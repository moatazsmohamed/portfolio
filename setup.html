إعداد صندوق رسائل العملاء

بتتعمل مرة واحدة بس في Supabase. لو اتعملت صح، الفورم وصندوق الرسائل هيشتغلوا على طول.

الخطوات

  1. دوس «نسخ السكريبت» تحت.
  2. افتح محرر SQL على مشروع مدار: ppihzxabbysozbdmweje → SQL Editor (لو طلب دخول، ادخل).
  3. جوه المحرر اعمل Ctrl+A ثم Delete — المحرر بيشغّل المحدّد فقط فلازم يبقى فاضي.
  4. Ctrl+V ثم دوس Run.
  5. آخر نتيجة لازم تطلّع OK — الدوال الستة اتعملت. ارجع هنا ودوس «افحص» للتأكيد.
